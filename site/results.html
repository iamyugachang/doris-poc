Step 03 · 實驗過程與全部結果

每一格、每一輪、每個 client 的原始結果

依 實驗設計 的故障矩陣，由 experiments/run_matrix.py 自動逐格執行：monitor → baseline 30s → break → 觀察 90s → measure → restore → settle → measure。每格跑三輪，每輪從全部 VM 重新開機開始。共 16 格、48 次執行。等級由 measure 依故障期間最後一段紀錄判定；中斷秒數 = 第一次失敗到下一次成功。

HOW TO READ怎麼看這頁

等級

讀寫正常 寫入與查詢在中斷後全部恢復　只讀 查詢可用、寫入持續失敗　不可用 查詢也失敗。arrow-flight 只做查詢：讀取正常 / 讀取失敗

影響秒數

失敗視窗（第一次 FAIL 到下一次 OK）＋卡頓（連續兩次操作間隔超過 5 秒，例如 client 卡在轉發給已卡住的 master）。含 client 自己的逾時等待：connect 3s、read/write 8s。

restore → 健康

從逆轉第一個故障到 3 FE / 3 BE alive、12 副本 OK 的秒數；crash 類另記 systemd 拉起的秒數。
